## 公众号版（深度 · 1500-2000 字）

标题：**找不到那首歌，我就量了它——短视频配乐其实可以不靠耳朵**

你有没有遇到过这种情况：剪片子的时候配乐最难。不是找不到歌，是**你不知道该找什么样的歌**。

更扎心的是，参考片里那段你以为"某首神曲"的配乐，可能压根**不存在于任何曲库里**。真实案例：参考片作者是用 Suno 现场生成的配乐，每支片子生成一次。三支片子听着像同一首，谱图互相关 0.84–0.89、RMS 包络互相关 0.44–0.60——**确实是同一首**，但它只存在于那三个文件里。

所以"找同一首"这条路，是死的。

### 一、那还能怎么办？

把「找同一首」降维成「找同一类」。

任何一首曲子，都能被压成四个客观的数。这四个数定了，风格就定了；风格定了，你就有筛子了。

**指标一 · 节拍（BPM）** —— 音乐的"步伐"。参考片三支片子全在 125–128 BPM。

**指标二 · 响度（LUFS）** —— 音乐的"音量人格"。参考片 integrated −12.8 LUFS、LRA 3.6 LU、true peak −2.3 dBFS。响度平稳、动态收窄，这是**垫底**的响度，不是主角的响度。

**指标三 · 谱质心（Hz）** —— 音乐的"明亮度"，即能量重心。参考片 **592 Hz**，极低。这意味着重低音铺底、中频极少。

**指标四 · 频段能量分布** —— 五段占比。参考片 0–120Hz **69%** / 120–500Hz 21% / 500–2k 4.7% / 2–6k 1.7% / 6–20k 3.3%。**七成能量压在最低频**。

谱质心低 + 低频占比高 = **重低音铺底型 lo-fi**。这个画像对应的不是某一首歌，而是一整类曲子的参数区间。

### 二、拿画像去曲库里筛

关键是要**机读**的曲库。incompetech 的 `pieces.json` 有 1443 首，每首带 bpm / genre / feel / instruments——能被程序筛的，才是好曲库。

按谱质心 + 频段分布 + BPM 客观打分，入选四首：

| 曲子 | BPM | 谱质心 | 频段分布 |
|---|---|---|---|
| Lobby Time | 129.2 | 178 Hz | 73/24/2/0/0 |
| Vibe Ace | 129.2 | 178 Hz | 78/19/3/0/0 |
| Inspired | 120.2 | 226 Hz | 76/15/9/0/0 |
| Airport Lounge | 129.2 | 196 Hz | 64/34/2/0/0 |
| *参考片基准* | *127.6* | *592 Hz* | *69/21/5/2/3* |

看出问题了吗？入选曲的**频段分布几乎重合**，但谱质心差得远（178 Hz vs 592 Hz）。

**这个差距如实留着，不硬凑。** 它说明替代曲在"低频够重"上到位，在"整体更亮更窄"上有偏差。**知道偏差在哪，比假装一致有用得多。**

### 三、无缝是能算出来的

第二个死结：随手截一段 30 秒铺底，结尾必然听得出接缝。配乐瞬间从"氛围"变成"噪音"。

但无缝根本不用靠听。完整四步：

**分离。** demucs 抽 no_vocals 轨（122 秒音频，M2 Pro CPU 上只跑 9 秒）。

**切在拍点上。** 128.4 BPM → 1 小节 = 1.869 s；在 RMS 变异系数 < 0.20 的稳定区（70–92 s）取整 12 小节 = **22.43 s**。

**等长交叉淡化。** 尾部 2 s 与头部做等长交叉淡化——接缝不在任何一个小节头上，耳朵抓不到。

**幅度归一。** RMS 归一到 0.113 + 软限幅（tanh，peak 0.856）。

**怎么验收？** 看循环点的一阶差分。实测接缝处最大 **0.0102**，全曲平均 **0.0107**——接缝不比别处更突，**无缝成立**。

### 四、三个真踩过的坑

**坑一 · 分离不等于干净。** 原片 vocals 轨有 27 段人声，分离后 no_vocals 轨仍剩 5 段残留，会听出"掏空感"。破法：先验证参考区间本身有没有人声——70–95.5 s 段 vocals 轨能量只占 **1.8%**，说明这曲子本来是纯器乐，抠出来的 loop 才不会有掏空感。

**坑二 · 代理会截断大文件。** `pieces.json` 这类大文件会被中途掐断，必须走 Range 分块下载。

**坑三 · 版权不能含糊。** 从朋友视频里分离出的 `ref_bgm_loop.mp3` **仅限自用 / 内部测试**，公开发布前必须换成原创或授权音乐。曲库每首都配同名 `.json` 记作者 / 许可证 / 来源，CC BY 4.0 公开发布需署名 `Music: <title> by Kevin MacLeod (incompetech.com) - CC BY 4.0`。

### 五、还有一句必须说

本机的四条 AI 音乐生成通路，实测**全灭**：MiniMax 音乐接口对新用户直接返回 2153「no longer available to new users」· Suno 无 key 且 api.suno.com 本机不通 · Mureka 无 key · ChatCut 要账号 + 积分。

**接口存在 ≠ 你能用。** 可用性要当天实测，不靠文档。

### 六、最后落到三个数

混音参数其实就三个：**−20 dB · 淡入 1 s · 淡出 2.5 s**。官方做法（生成一次原创免版税音乐 → 压到 −20 dB 垫在配音底下 → 淡入 1s 淡出 2.5s）就是这三个数。

六步走完：从参考片到成片，每一步的产物都是下一步的输入，整条链**可复算、可交接、可外包**。

> **一句话记住**：先把参考片量成数，再让数字替你选曲。

## 小红书版（精简 · 350 字 + 8 张图）

参考片的配乐是作者用 Suno 现场生成的，每支片子生成一次 —— 世界上**不存在「同一首」**可以去找。四条 AI 音乐接口也全灭了。

② **响度** −12.8 LUFS（音量人格）
