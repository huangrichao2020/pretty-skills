# vibe-ui-methodology · VibeCoding 视觉设计统一方法论

> **定位**：HTML / PPT / PDF 三场景 UI 色彩系统与国风纹样的统一方法论 skill。
> 沉淀自「才巨智能 VibeCoding 教程系列」两本 PDF（19页 UI色彩 + 30页 国风纹样）。

---

## 核心能力

三场景全覆盖的视觉设计规范：
- **HTML/Web**：60-30-10 法则、50-900 色阶、三层 Token、WCAG 对比度、深色模式
- **PPT/演示**：投影对比度修正（7:1+）、Hero/Supporting 色彩节奏、国风四主题浅色版
- **PDF/书籍**：打印色彩（CMYK 思维）、章首页/目录配色、跨章节一致性

四大国风配色主题（青花/朱砂金/黛蓝金/墨绿金）+ 30 种纹样话术库。
