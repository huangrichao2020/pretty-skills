## P0 · 封面 / 定位

- **标题**：VibeCoding UI 视觉设计统一方法论
- **副标**：把色彩变成系统，而不是感觉
- **章节类型**：封面 / 定位
- **核心主张**：任何 HTML/CSS/SVG/可视化输出，先调用本方法论拿到配色规范与纹样话术，再动手写代码 —— 它是所有视觉产出的「总入口」
- **认知锚点**：「一套色彩系统 = 1 主色阶 + 4 语义色 + 1 中性色 ≈ 60 个色值撑起 100% 界面」—— 视觉好不好看，决定权在系统不在审美
- **关键要点**：
  - 沉淀自才巨智能 VibeCoding 教程系列（色彩手册 19 页 + 国风纹样 30 页）
  - 一句话纪律：配色成系统 / 提示词给参数给规则给禁令 / 纹样用 SVG 不用位图
  - 触发场景：HTML、PPT（配 tencent-pptx）、PDF/橙皮书（配 huashu-book-pdf）、UI 配色、新中式视觉都应先调本 skill
- **数据 / 数字**：3 大纪律 · 60-30-10 · 50-900 色阶 · 4 套国风 · 30 种纹样
- **金句**：把色彩变成系统，而不是感觉。

## P1 · 现象 / 痛点

- **标题**：AI 视觉翻车三大病
- **副标**：不是不会画，是没系统、没参数、没禁令
- **章节类型**：现象 / 痛点
- **核心主张**：AI 生成的界面常见三类病 —— 凭感觉配色、模糊提示词、位图纹样，根子都在「凭感觉」而非「按规范」
- **认知锚点**：「凭感觉 = 随机；按规范 = 可控」—— 翻车不是能力问题，是纪律问题
- **关键要点**：
  - 病① 凭感觉配色：主色铺满整页，没有强调，看完像没看
  - 病② 模糊提示词：「好看的紫」「高级的灰」让 AI 随机发挥，每次都不一样
  - 病③ 位图纹样：不可缩放 / 不可换色 / 不可平铺，换场景就废
- **数据 / 数字**：3 类病（凭感觉 / 模糊词 / 位图）
- **金句**：视觉翻车的根因，不在工具在纪律。

---

## P2 · 诊断 / 根因

- **标题**：病根不在工具，在有没有系统
- **副标**：凭感觉 → 随机 → 翻车，vs 成系统 → 参数 → 可控
- **章节类型**：诊断 / 根因
- **核心主张**：差异不在 AI 会不会画，而在是否有「系统 + 参数 + 禁令」—— 没有这三者，再强的生成模型也只会随机
- **认知锚点**：「换主题只改语义层映射，不动组件代码」—— 系统让改动成本趋近零
- **关键要点**：
  - 凭感觉路径：色值硬编码在组件 → 模糊形容词驱动 → 换主题改一堆 → 深色模式直接反相失真
  - 成系统路径：三层 Design Token → HSL 参数 + 角色 + 禁用清单 → 换主题只改语义层 → 深浅双套语义映射
  - 结论：把「立规」前置，视觉质量立刻上一个台阶
- **数据 / 数字**：1 个分叉（感觉 vs 系统）· 3 层 Token
- **金句**：先立规，再动手，AI 才是搭档不是甲方。

## P3 · 原理 / 色彩系统

- **标题**：色彩系统三件套
- **副标**：60-30-10 比例 + 50-900 色阶 + 三层 Design Token
- **章节类型**：原理 / 方法论
- **核心主张**：用「配比约束 + 色阶生成 + 分层变量」三件套，把主观审美变成可复用的工程系统
- **认知锚点**：「强调之所以是强调，恰恰因为它稀缺」—— 先把 90% 交给中性色，主色只在关键行动点出现
- **关键要点**：
  - 60-30-10：60% 主色调（背景留白）/ 30% 辅助色（次级区块）/ 10% 强调色（按钮·链接·关键数据）
  - 50-900：固定色相与饱和度，只让明度从 97% 降到 15%；主色公式 HSL(h,30%,50%) → 紫罗兰 #5A4E8C
  - 三层 Token：原始层（是什么色）→ 语义层（做什么用）→ 组件层（用在哪）；禁止组件硬编码色值
- **数据 / 数字**：60/30/10 配比 · 10 级色阶 · 3 层架构
- **金句**：稀缺，是强调存在的唯一理由。

## P4 · 原理 / 国风配色与纹样

- **标题**：四套国风配色 + 五步纹样公式
- **副标**：青花瓷 / 朱砂金 / 黛蓝金 / 墨绿金 · 30 种话术库
- **章节类型**：原理 / 方法论
- **核心主张**：国风不是堆元素，而是用「配色主题 + 五步描述公式 + 衍生四法」可控地生成 SVG 纹样
- **认知锚点**：「纹样用 SVG 不用位图」—— 矢量可缩放 / 可换色 / 可平铺，位图不可控
- **关键要点**：
  - 四套主题：青花瓷（清雅素净）/ 朱砂金（喜庆华贵）/ 黛蓝金（沉稳高端）/ 墨绿金（自然雅致）
  - 五步公式：骨架结构 → 主体元素 → 构成方式 → 色彩（注明色值）→ 风格与用途
  - 五大类型 30 种话术：几何 7 / 植物 6 / 动物 6 / 自然天象 5 / 吉祥 6
  - 衍生四法：换色 / 骨架重组 / 抽象简化 / 跨界融合
- **数据 / 数字**：4 套主题 · 5 步公式 · 5 大类 · 30 种话术
- **金句**：国风是规范，不是素材堆砌。

## P5 · 操作 / 场景纪律

- **标题**：三场景速查 + 深色模式 + 无障碍
- **副标**：同套规范，不同参数；投影吃色、打印柔和
- **章节类型**：操作 / 纪律
- **核心主张**：HTML / PPT / PDF 共用一套色彩系统，但必须按输出媒介调整对比度、饱和度、底色与深色策略
- **认知锚点**：「深色模式禁止整页深色底（PPT）；纯白文字配浅主色要用 600+」—— 媒介决定参数
- **关键要点**：
  - HTML：对比度 4.5:1(AA)、饱和度 30%、支持深色模式、底纹透明度 0.03-0.05
  - PPT：纯白优先、对比度 7:1+（投影损失）、饱和度 40-50%、字号≥18px、禁止整页深色底
  - PDF：白/米白底、对比度 4.5:1、饱和度 25%、正文 95% 黑 #1A1A1A、纹样 opacity≥0.08
  - WCAG 强制：正文 4.5:1、大字号 3:1、色盲友好须图标/文字双重提示
- **数据 / 数字**：3 场景 · 4.5:1 底线 · 7:1 PPT 补偿
- **金句**：媒介决定参数，规范保证一致。

## P6 · 收束 / 速查

- **标题**：验收清单 + 视觉红线
- **副标**：记牢双清单，任何视觉产出先过这两关
- **章节类型**：收束 / 速查
- **核心主张**：交付前用「验收清单」核对一致性/层级/对比度/语义/双模式，并用「视觉红线」排除六类硬伤
- **认知锚点**：「全文搜索 #，硬编码色值应为 0」—— 一致性是系统存在的证明
- **关键要点**：
  - 验收（按输出分三套）：一致性（0 硬编码）/ 层级（眯眼最醒目）/ 对比度 / 语义（绿黄红蓝直觉）/ 双模式
  - 视觉红线：禁纯黑 #000 正文 / 禁纯灰纯红纯蓝廉价色 / 禁大色块>30% / 禁只靠颜色 / 禁组件硬编码 / 禁模糊形容词进提示词
  - 调用决策树：HTML→配色+纹样+提示词；PPT→投影对比度+国风映射；PDF→打印色彩+章首页
  - 协作：huashu-book-pdf 依赖本 skill 配色、tencent-pptx 互补本 skill 投影修正
- **数据 / 数字**：5 项验收 · 6 条红线 · 3 分支决策树
- **金句**：把色彩变成系统，而不是感觉。
