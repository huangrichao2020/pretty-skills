# VibeCoding UI 视觉设计统一方法论 · 融合稿（公众号 / 自媒体 / AI 阅读 三用）

> 一套规范，三场景通吃。把色彩变成系统，而不是感觉。

## 一句话定位

任何 HTML / CSS / SVG / 可视化输出，先调这套方法论拿配色规范与纹样话术，再写代码。它是所有视觉产出的「总入口」，覆盖 Web 页面、PPT 演示、PDF/橙皮书三大场景。

## 三大纪律（顶层底线）

1. **配色成系统而非凭感觉**：1 主色阶 + 4 语义色 + 1 中性色 ≈ 60 个色值，撑起 100% 界面。
2. **提示词给参数给规则给禁令**：模糊形容词让 AI 随机；HSL 参数 + 角色分配 + 禁用清单让 AI 精确。
3. **纹样用 SVG 不用位图**：矢量可缩放 / 可换色 / 可平铺，位图不可控。

## 色彩系统三件套

- **60-30-10 黄金比例**：60% 主色调（背景留白）、30% 辅助色（次级区块）、10% 强调色（按钮·链接·关键数据）。强调之所以是强调，恰恰因为它稀缺。
- **50-900 色阶生成法**：固定色相与饱和度，只让明度从 97% 降到 15%。主色公式 HSL(h,30%,50%) → 紫罗兰示例 #5A4E8C。
- **三层 Design Token**：原始层（是什么色）→ 语义层（做什么用）→ 组件层（用在哪）。禁止组件硬编码色值；换主题只改语义层映射。

## 国风配色与纹样

- **四套开箱即用主题**：青花瓷（清雅素净）/ 朱砂金（喜庆华贵）/ 黛蓝金（沉稳高端）/ 墨绿金（自然雅致）。
- **五步纹样公式**：骨架结构 → 主体元素 → 构成方式 → 色彩（注明色值）→ 风格与用途。
- **30 种话术库**：几何 7 / 植物 6 / 动物 6 / 自然天象 5 / 吉祥 6；衍生四法：换色 / 骨架重组 / 抽象简化 / 跨界融合。

## 三场景速查（同套规范，不同参数）

| 维度 | HTML/Web | PPT/演示 | PDF/书籍 |
|------|---------|---------|---------|
| 对比度 | 4.5:1 (AA) | 7:1+（投影损失） | 4.5:1 |
| 饱和度 | 30% | 40-50%（投影吃色） | 25%（打印柔和） |
| 字色 | gray-800 | gray-800（≥18px） | 95% 黑 #1A1A1A |
| 深色模式 | 支持 | 禁止整页深色底 | 不支持 |

## 验收清单 + 视觉红线

**验收（按输出分三套）**：一致性（全文 0 硬编码色值）/ 层级（眯眼最醒目）/ 对比度 / 语义（绿黄红蓝直觉）/ 双模式。

**视觉红线（不许违反）**：禁纯黑 #000 正文 / 禁纯灰纯红纯蓝廉价色 / 禁大色块 >30% / 禁只靠颜色传信息 / 禁组件硬编码色值 / 禁模糊形容词进提示词。
