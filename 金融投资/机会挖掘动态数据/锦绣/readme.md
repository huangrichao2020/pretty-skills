# 机会挖掘动态数据 · 融合稿（公众号 + 自媒体 + AI 阅读三用）

> 一句话：把「微信级股市问答」从硬编码模板升级成 NeoData 真数据动态引擎，数据可验证、不再凭印象。

## 公众号版（科普向）

你有没有遇到过那种「看起来很对」的股市回答？板块名是编的、涨停数是估的，读完心里没底。

2026-08-20，我们把「机会挖掘」这个微信助理的核心技能从 v0.3 推到了 v0.4——**最大的变化是：它不再背模板，而是实时去抓真实盘面**。

具体做了三件事：

1. **真数据动态组装**：盘中机会场景原来写死板块和涨停股，现在改读 `sector_leaders` 和 `limit_up_stocks` 两个真字段，由 `collect_intraday_data()` 一次联动采齐「板块涨幅 TOP + 涨停股 TOP + 板块资金 TOP」。
2. **6 处数据可信度修复**：之前市场指数能抓到日期当数值（2026.0）、下跌家数显示 5 实际 5069、上涨占比 0.76 实际 0.08、情绪温度算成 55 把冰点误判成高潮……全部重写。数据错了，结论再漂亮也是胡说。
3. **一个一票否决级铁律**：NeoData 返回的换行是字面 `\n`（反斜杠加 n），不是真换行。所有解析器第一行必须先 `replace("\\n","\n")` 再分割，否则整张表解析失败、数据全空。

配套还做了 v0.3.1 排版精修（微信一屏可读、圆数字编号、末尾「一句话」动作清单）和一条铁律：**直接给答案，不要工作日志式的元解释**——用户要的是 Reuters 式快讯，不是「我现在去拉数据」。
