# 4 维度分析（板块 × 资金 × 基本面 × 消息面）

> 从 7 条件选出的 3-5 只候选中，筛出"短线冲高型"（3 维满足）。
> **资金面权重最高**——短线本质上是资金的博弈。

## 一、4 维度评分框架

```
4 维度评分 = 板块景气(0/1) + 资金面(0/1) + 基本面(0/1) + 消息面(0/1)
            = 0 ~ 4 分

4 分 → 持续行情型(重仓 3-5 天)
3 分 → 短线冲高型(次日跑路) ★ 目标
≤ 2 分 → 不建议(不操作)
```

## 二、维度 1 · 板块景气度（权重：中）

### 2.1 评估表

| 评估项 | 阈值 | 满足? | 证据 |
|--------|------|--------|------|
| 政策催化 | 国务院/央行/证监会 政策文件 | ☐ 有 / ☐ 无 | (查近期政策文件、行业新闻) |
| 订单增长 | 板块订单数据 | ☐ 增 / ☐ 减 | (查产业链订单数据) |
| 价格上行 | 上游原料价格 | ☐ 涨 / ☐ 跌 | (查文华财经 / akshare) |

**评分标准**（满足 2/3 即"景气"）：
- ✅ 满足 ≥ 2 = 板块景气度高（1 分）
- ❌ 满足 < 2 = 板块景气度低（0 分）

### 2.2 产业链位置

| 位置 | 持续性 |
|------|--------|
| 核心受益（上游 / 中游 / 下游）| ⭐⭐⭐⭐ |
| 弹性受益 | ⭐⭐⭐ |
| 概念关联 | ⭐（仅蹭概念，不进推荐）|

### 2.3 资金切向

| 信号 | 判断 |
|------|------|
| 资金切向本板块 | ✅ 短线弹性大 |
| 资金切离本板块 | ❌ 警惕 |

- ❌ 满足 < 3 = 资金面弱（0 分）

### 3.2 资金节奏判断（核心）

| 节奏 | 信号 | 操作 |
|------|------|------|
| 洗盘后加速吸筹 | 缩量 → 放量 + 主力净流入递增 | ✅ 强势 |
| 高位派发 | 放量 + 主力净流出 | ❌ 警惕 |
| 平淡无奇 | 量比 < 1 + 主力净流入 < 0.5 亿 | ⚠️ 观望 |

### 决策表

|------|------|------|

## 七、4 维度常见误判

| 误判 | 症状 | 正确做法 |
|------|------|----------|
| 资金面强 = 必涨 | 看到主力净流入大就买 | 4 维评分 ≥ 3 才操作 |
| 基本面好 = 短线必涨 | 营收 +30% 就重仓 | 基本面是过滤器，不是买入信号 |
| 研报上修 = 必涨 | 看到大行研报上修就买 | 研报 + 量价 + 主力流入 三者共振 |
| 板块景气 = 个股必涨 | 板块政策好买龙头 | 板块 + 个股筹码 + 资金面 三者共振 |

## 八、口诀

> **资金为王，板块为辅，消息为引，基本面是过滤器。**
> **资金面独大：3 满足 = 强；其余 3 维各看 2-3 满足 = 良。**
> **4 维全满足警惕过热，单独 1 维警惕陷阱。**
