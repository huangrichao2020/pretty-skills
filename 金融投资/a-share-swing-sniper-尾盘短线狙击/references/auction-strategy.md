# 竞价策略（9:15-9:25 集合竞价）

> **这 10 分钟决定吃肉还是吃面。** 3 情景判断 + 主力成本线 + 压力位，3 个核心要素。

## 一、3 情景判断框架

| 情景 | 开盘价 | 竞价成交量 | 主力净流入 | 冲高概率 | 操作 |
|------|--------|------------|------------|----------|------|
| **🟢 乐观** | 高开 3%-5% | > 前日 | > 0 | **高** | 竞价区间分批买入 |
| **🟡 中性** | 平开/小幅低开 | < 前日 | 持平 | **中** | 观望 + 等放量突破 |
| **🔴 悲观** | 低开 2%+ | 放大 | 净流出 | **低** | **不买入**，规避大面 |

## 二、🟢 乐观情景（高开 3%-5%）

### 2.1 触发条件（3 条 AND）

| 条件 | 阈值 | 实际 |
|------|------|------|
| 开盘价相对昨日收盘 | **+3% 到 +5%** | ___% |
| 集合竞价成交量 | **> 前日同时段** | ___ |
| 竞价阶段主力净流入 | **> 0** | ___亿 |

### 2.2 分批买入节奏

```
9:20 前:  挂 1/3 仓位 (试探)
9:20-9:23: 加 1/3 仓位 (确认)
9:24-9:25: 加 1/3 仓位 (收尾)
```

**仓位**：单只 ≤ 30%

⚠️ **9:20 后不能撤单** → 严控仓位

### 2.3 风险

- 高开 5%+ 警惕诱多
- 高开 + 竞价量 < 前日 = 高开低走概率大

## 三、🟡 中性情景（平开 / 小幅低开）

### 3.1 触发条件

| 条件 | 阈值 | 实际 |
|------|------|------|
| 开盘价相对昨日 | **0% 到 -2%**（平开 / 小幅低开）| ___% |
| 集合竞价成交量 | **< 前日同时段** | ___ |
| 主力净流入 | **持平** | ___亿 |

### 3.2 操作：观望 + 等放量突破

```
9:25-9:30:  不操作, 观察开盘 5 分钟
9:30-9:35:  若放量突破开盘价 + 主力净流入 → 买入 1/2 仓位(12-15%)
9:35 后:    若未突破 → 放弃
```

### 3.3 升级判断

- 9:30 后高开高走 + 主力持续流入 → 升级乐观, 加仓
- 9:30 后低开低走 + 主力净流出 → 升级悲观, 放弃

## 四、🔴 悲观情景（低开 2%+）

### 4.1 触发条件（任一）

| 条件 | 阈值 | 实际 |
|------|------|------|
| 开盘价相对昨日 | **< -2%** | ___% |
| 集合竞价放量 | **> 前日 1.5 倍** | ___ |
| 主力净流入 | **< 0**（净流出）| ___亿 |

### 4.2 操作：不买入，规避大面

```
9:15-9:25:  全部不操作
9:30-9:35:  观察是否修复
9:35 后:    不操作, 放弃
```

### 4.3 警惕信号（必须放弃）

| 信号 | 风险 |
|------|------|
| 主力净流出 > 7 亿 | 9-4 案例重现，大面前兆 |
| 散户净流入 > 8 亿 | 主力出货，散户接盘 |
| 集合竞价放量但低开 | 主力故意压盘，诱多陷阱 |
| 尾盘最后 3 分钟放量 | 高位派发 |

**为什么"竞价放量"反而是悲观？**

主力想跑，需要把货分给很多散户。所以会故意在集合竞价放量压盘，等开盘后散户接盘——这就是"诱多"。

## 五、主力成本线判断（核心）

### 5.1 关键价位

| 价位 | 计算方法 | 操作信号 |
|------|---------|---------|
| **主力成本线** | 近 20 日均价 × 主力增仓调整 | 站稳 → 可买；跌破 → 减仓 |
| **5 日均线** | 近 5 日均价 | 跌破 → 减仓 |
| **压力位** | 前高 / 套牢盘密集区 | 放量突破 → 加仓 |
| **目标位** | 主力成本 + 压力位突破后 | 前高（回补套牢盘）|

### 5.2 主力成本线公式（简化）

```python
def main_cost_line(prices_20d, main_net_inflows_5d):
    """
    简化: 近 20 日均价 + 主力净流入调整
    """
    ma20 = sum(prices_20d) / 20

    # 主力净流入调整系数
    net_inflow_ratio = sum(main_net_inflows_5d) / 100  # 归一化
    if sum(main_net_inflows_5d) > 0:
        return ma20 * (1 + 0.02)  # 主力吸筹推升 +2%
    else:
        return ma20 * (1 - 0.02)  # 主力抛压下行 -2%
```

### 5.3 操作矩阵

| 价位 | 站位 | 操作 |
|------|------|------|
| 主力成本线 | 站稳 | ✅ 买入 |
| 5 日均线 | 站稳 | ✅ 持有 |
| 5 日均线 | 跌破 | ❌ 减仓 |
| 压力位 | 突破 + 放量 | ✅ 加仓 |
| 前高 | 触及 | 🎯 止盈 |

## 六、3 选 1 卖出条件（盘中监控）

### 6.1 任一触发立即减仓

| # | 条件 | 阈值 | 含义 |
|---|------|------|------|
| 1 | **放量滞涨** | 放量但涨幅 < 1% | 主力高位派发 |
| 2 | **跌破 5 日均线** | 收盘价 < 5 日均线 | 短线趋势破坏 |
| 3 | **主力净流出** | 净流出 > 前日净流入 50% | 主力出逃 |

### 6.2 卖出节奏

- 9:30-10:00：开盘观察，不操作（避免波动）
- 10:00-14:00：盘中监控，3 选 1 触发即卖
- 14:00-15:00：尾盘观察，如持有 → 评估次日

## 七、止盈止损

### 7.1 止盈（3 阶段）

| 目标位 | 标准 | 锁利 |
|--------|------|------|
| 目标 1 | 主力成本 + 5% | 卖 1/2 |
| 目标 2 | 主力成本 + 10% | 卖 1/2 |
| 目标 3（冲高跑路位）| 前高 / 压力位 | **全部清仓** |

### 7.2 止损

| 触发条件 | 操作 |
|----------|------|
| 跌破 5 日均线 | 减仓 1/2 |
| 跌破主力成本线 | 全部卖 |
| 单日跌幅 > 8% | 强制止损 |

### 7.3 风险敞口

- 单只最大亏损 = 30% 仓位 × 8% = **2.4%**
- 总账户最大日亏损 = 2.4% × 3-5 只 = 7-12%（可接受）

## 八、关键提醒

### ⚠️ 9:20 前可撤单，9:20 后不能撤
- 9:20 是撤单截止点
- 9:20 后单子必须成交 → 严控仓位

### ⚠️ 尾盘最后 3 分钟警惕诱多
- 14:57-15:00 尾盘放量 + 拉最高价 = 主力诱多
- 次日低开概率大

### ⚠️ 9:30 开盘 5 分钟是"试金石"
- 高开高走 + 放量 = 强势确认
- 高开低走 + 缩量 = 弱势，放弃
- 平开震荡 = 观望
