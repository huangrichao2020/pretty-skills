# 9-4 大面案例复盘

> **核心数据**：主力净流出 7.97 亿 + 散户净流入 8.29 亿 = 精确对称的"主力出货 + 散户接盘"
> **教训**：下周一若出现类似结构 → 立即减仓，不接刀

## 一、案例数据

### 1.1 当日资金结构

| 角色 | 资金流向 | 金额 | 占比 |
|------|---------|------|------|
| 主力（机构 + 大单）| 净流出 | **7.97 亿** | 流出端 |
| 散户（中单 + 小单）| 净流入 | **8.29 亿** | 流入端 |
| 差值 | 主力出 = 散户进 | **+0.32 亿** | 精确对称 |

### 1.2 关键时点

| 时点 | 状态 |
|------|------|
| 9-3（前日）| 主力净流入，洗盘后吸筹 |
| 9-4（当日）开盘 | 主力开始净流出 |
| 9-4 10:00 | 累计 -3 亿 |
| 9-4 11:30 | 累计 -5 亿 |
| 9-4 14:30 | 累计 -7.97 亿 |
| 9-4 14:57-15:00 | 尾盘最后 3 分钟放量（诱多）|
| 9-4 收盘 | 大阴线封死跌停 |
| 9-5（次日）| 低开 -5%，散户割肉 |

## 二、为什么这是"大面"？

### 2.1 资金结构信号

```
主力流出 7.97 亿  →  主力不看好后市
散户流入 8.29 亿  →  散户接盘
差值 0.32 亿     →  精确对称（巧合？非也 = 主力精准出货给散户）
```

**这就是"主力派发 + 散户接盘"的最经典信号**。

### 2.2 散户心理路径

```
9:30 看到开盘跌 2%：哎，跌了，要不要止损？
9:45 跌到 -5%：要不要割肉？
10:00 反弹到 -3%：没事，是洗盘
10:15 反弹到 -1%：主力在拉升，继续拿着
10:30 涨到 +1%：赚回来了！
11:00 涨到 +3%：主力洗盘结束
11:30 涨到 +5%：再加仓！
13:00 涨到 +4%（开始下跌）：是不是要跌了？
14:00 跌到 -2%：没事，会反弹
14:30 跌停：完了，封死了
15:00 收盘 -10%：明天低开跑路
9-5 次日 -5% 低开：割肉
```

**实际结果**：涨到 +5% 是主力故意拉高出货，跌停是砸盘出货，最后全天净流出 7.97 亿。

### 2.3 主力操盘路径

```
9-3 (前日)  → 主力净流入 5 亿（洗盘后吸筹，准备拉升）
9-4 09:30   → 主力开始卖出，价跌量增
9-4 10:00   → 卖 3 亿，价已跌 5%（散户割肉）
9-4 10:30   → 价反弹到 -1%（主力故意拉高出货）
9-4 11:00   → 拉高到 +3%（诱多，让散户以为是洗盘结束）
9-4 11:30   → 拉到 +5%（诱多高潮）
9-4 13:00   → 主力开始大笔卖出
9-4 14:00   → 价跌到 -2%（散户接盘）
9-4 14:30   → 主力再砸 2 亿，跌停
9-4 15:00   → 主力累计净流出 7.97 亿
9-5 次日    → 低开 -5%，散户割肉
```

## 三、本 skill 如何防御？

### 3.1 7 条件选股时

- ✅ chip 过滤会排除高位（chip > 85% 直接排除）
- ✅ 涨幅过滤会排除涨停板
- ✅ 5 日量过滤会排除量能异常

### 3.2 3 选 1 盘中监控

如果 9-4 当天你在盘中，3 选 1 任意一个都会触发：
- 放量滞涨（10:00 后持续放量但涨幅 < 1%）
- 跌破 5 日均线（开盘即破）
- 主力净流出（持续监控会发现 > 前日 50%）

**任一触发 → 立即减仓 → 规避下午跌停的大面**

### 3.3 季节 × chip 过滤

- 9 月是"秋伐"季节
- 仓位上限 30-50%
- 单只 ≤ 30% → 即便跌停也只亏 3%
- 现金 ≥ 20% → 跌停后还有钱加仓

## 四、识别公式（每天盘中跑）

```python
def check_9_4_pattern(main_net_inflow, retail_net_inflow, threshold_main=-7, threshold_retail=8):
    """
    检测是否出现 9-4 大面前兆
    """
    if main_net_inflow < threshold_main and retail_net_inflow > threshold_retail:
        return True, "9-4 大面前兆：主力出 - 散户进"
    return False, None
```
