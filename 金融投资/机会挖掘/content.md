## P1 · 4 段式输出范式（v0.3 排版）

- **输出结构**：判断 / 依据 / 动作 / 风险，用 ⚠️✅❌🟡 4 类图标替代标签。
- **字数铁律**：≤500 字 · 1-2 屏微信可读完，超字重写。
- **加粗规则**：每段 ≤3 处（数字 / 关键词 / 股票名 / 一句话动作）。
- **标的不适配**：每只 `股票名` inline code 灰底小一号；多只以 ` / ` 分隔。
- **箭头语言**：`→` 主标题到核心词 · `·` 同级并列 · `=` 触发条件。
- **删除项**：【判断】标签块 / @NeoData 后缀 / `>` 引用块 / markdown 表格。
- **认知锚点**：手机微信界面里一段红绿点缀、带 emoji 图标的短答，视觉清爽像聊天而非报告。

## P2 · 三通道数据获取

- **硬约束**：没有数据不回答；每条判断必带数据源标签。
- **通道① NeoData**：自然语言查板块涨跌 / 资金流 / 涨停梯队 / 概念板块（主用）。
- **通道② westockdata**：命令行精确数据 K 线 / 财务 / 技术指标 / 公告（备用）。
- **通道③ WebSearch**：全球消息 / 美股 / 港股 / 突发新闻（补位）。
- **优先级**：NeoData → westockdata → WebSearch。
- **失败兜底**：API 失效时明说「数据缺失」，给基于经验的兜底并标注，不瞎编。
- **认知锚点**：三条数据管道汇聚成一个「可信结论」节点，管道分别标注 NeoData/westockdata/WebSearch 三色。

## P3 · 接盘防御 5 铁律

- **用途**：决策类回答（上车 / 加仓 / 抄底）前置检查，触发 ≥3 条 → 不参与。
- **铁律① 不追首板**：首板次日分歧才是介入点，当日追 = 鱼尾接盘 70%+。
- **铁律② 不追板块涨幅前 3**：前 3 多为鱼尾（已涨 30%+，主力在出货）。
- **铁律③ 不接机构减持**：减持公告后 1 周跌多涨少，7 日内标的拉黑。
- **铁律④ 不抄底无量阴跌**：5 日跌 ≥10% + 量 <20 日均 60% + 无反弹阳 → 三项全中坚决不抄。
- **铁律⑤ 不参与 20cm 跟风股**：炸板率 >60%，只买龙头不碰跟风。
- **认知锚点**：一面盾牌上刻「5」，五道红色警戒线交叉，强调「防御优先于进攻」。

## P4 · 鱼身定位

- **必带**：每个回答明确主线 / 个股处于鱼头 / 鱼身 / 鱼尾哪段。
- **鱼头**：底部启动（20 日 ≤15% · 量比 <1.2）· 操作 = 买入建仓。
- **鱼身**：主升浪中段（20 日 15-50% · 量比 0.8-1.5）· 操作 = 持有 + 8-12% 移动止盈。
- **鱼尾**：末段加速（20 日 ≥50% · 量比 ≥1.5 · 换手 >15%）· 操作 = 止盈 / 不参与。
- **鱼尾信号**：量比 ≥1.5 / 换手 >15% / 振幅 >8% / 高位放量滞涨 / 前 3 未进 TOP3。
- **判定**：5 个信号亮起 ≥3 个 → 鱼尾判定 → 不参与 / 立即止盈。
- **认知锚点**：一条鱼形曲线从左（头）到右（尾），尾段标红警示，中段标金持有。

## P5 · 龙头矩阵 + 情绪温度

- **龙头矩阵**：个股罗列必走三段 🥇龙头(持有) / 🥈跟风(减仓) / 🥉补涨(观望)。
- **龙头标准**：涨幅 / 量能前 3 + 业务最纯（≥80%）+ 封单坚决 + ≥3 机构席位。
- **情绪温度**：4 维评分（涨停 30% + 上涨占比 30% + 续涨 20% + 跌停 20%）归一 0-100°。
- **6 阶段周期**：冰点(0-30) → 修复 → 升温 → 高潮(70-90) → 分化 → 退潮(<40)。
- **多周期对比**：今日 / 5 日 / 10 日 / 20 日均；今日 - 20 日均 ≥15° → 顶部警惕分化。
- **量价关系**：涨停扩 + 量缩 = 顶部；指数跌 + 量缩 = 抛压衰竭；胜率 30% → 65%。
- **认知锚点**：一个金字塔（龙头尖 / 跟风中 / 补涨底）+ 一条温度曲线标注 6 阶段色带。

## P6 · 9 类场景 + 暴跌日实战验证
