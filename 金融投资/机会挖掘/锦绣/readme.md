## 一、机会挖掘是什么（公众号开场）

你有没有遇到过这种「股市 AI 助手」：一问「明天能不能上车」，它回你一句「明天继续涨是必然的」——没有数据、没有前提、没有退出条件，纯靠嘴。

这种回答在实战里就是接盘陷阱。

**机会挖掘**（英文 `idea-trade-qa`）做的是另一件事：把一套成熟的交易方法论（idea-to-trade v1.8）工具化，变成你在微信里问一句、30 秒内回一段、**每段都带数据、带前提、带止损线**的股市问答助手。

它不替你做决定，它替你把「凭什么这么判断」讲清楚。

## 二、4 段式输出：为什么短反而更准（自媒体稿）

机会挖掘的回答永远控制在 **250–500 字、1-2 屏**，结构固定四段：

- **判断**：一句话给方向（带鱼身定位）。
- **依据**：3-5 条，每条都带数字 + 数据源。
- **动作**：1-3 条，必带量化阈值（如「高开 ≥3% 才上车」）。
- **风险**：鱼尾信号 + 「非投资建议」。

排版上用 ⚠️✅❌🟡 四类图标替代死板标签，标的用 `` `股票名` `` 灰底小一号，数字和关键词才加粗——读起来像聊天，不像一份 markdown 报告。

**关键纪律**：没有数据不回答。每条判断必须走 NeoData / westockdata / WebSearch 三通道拿真实盘面，缺数据就明说缺，绝不瞎编。

## 三、三道防线，挡住「接盘」（AI 阅读 · 结构化）

机会挖掘最值钱的，是它回答前先过的三道防御：

**① 接盘防御 5 铁律**（决策类前置检查，触发 ≥3 条直接不参与）
1. 不追首板（次日分歧才是介入点）
2. 不追板块涨幅前 3（多为鱼尾诱多）
3. 不接机构减持（7 日内减持拉黑）
4. 不抄底无量阴跌（量 <20 日均 60% 坚决不抄）
5. 不参与 20cm 跟风股（炸板率 >60%）

**② 鱼身定位**（每段必带）
鱼头=底部启动（买入）· 鱼身=主升浪中段（持有+移动止盈）· 鱼尾=末段加速（止盈/不参与）。5 个鱼尾信号（量比≥1.5 / 换手>15% / 振幅>8% / 高位放量滞涨 / 前 3 未进 TOP3）亮 ≥3 个 → 鱼尾判定。

**③ 龙头矩阵 + 情绪温度**
个股罗列必分三段：🥇龙头（持有）/ 🥈跟风（减仓）/ 🥉补涨（观望）。大盘必带情绪温度（0-100° 六阶段：冰点→退潮），今日 - 20 日均 ≥15° 警惕分化。龙头矩阵 + 接盘防御双重过滤，胜率从追跟风 30% 拉到买龙头 65%。
